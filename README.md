# 夜航音乐工作室

安装：`npm install`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build -d`，访问 http://localhost:18027 。

## 功能与设计

- **64 条轨道**：适合较大的现场编制。编排与混音台都按固定行高虚拟滚动，
  只渲染视口内的行；滚出屏幕的轨道仍然完整参与播放与录音。
- **可解释的声部预算**：限制的是「同时发声的合成声部数」（默认 128），
  而不是轨道数。现场按住 / 正在录音的声音永不因预算被掐；回放声部按轨道
  优先级让位；同一条轨道同一瞬间的全部音符（一个和弦）只会整组接受或整组
  拒绝，绝不出现半个和弦。详见 `docs/voice-budget.md`。
- **受限可见**：编排行、混音条和底部状态栏都会显示哪些轨道被限制、原因
  （已让位 / 整组未排入）以及当前占用的声部数。
- **真实声道**：混音推子、静音、优先级都绑定轨道 id 与真实混音总线，
  与可见行、滚动位置无关；静音 / 删轨立即归还声部与总线。
- **存档兼容**：旧版 8 轨作品原样载入（缺失的声部优先级补默认值）；
  超出预算的大作品完整保存全部音符，保存与提交从不参考预算。

## 命令

- `npm run dev` — 本地开发
- `npm run typecheck` — 类型检查
- `npm test` — 单元与集成测试（Vitest）
- `npm run build` — 生产构建
